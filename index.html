Como usar este guia

Este guia foi criado para quem deseja iniciar ou aprofundar sua prática pessoal com banhos de ervas[cite: 2]. O objetivo não é ensinar uma receita automática para resolver qualquer situação, mas ajudar você a compreender a finalidade de cada banho, o papel de cada erva e a importância de uma intenção clara[cite: 2].

Utilize o menu lateral para navegar entre os módulos, explorar os 48 banhos divididos por finalidades ou clicar nas ervas para cruzar as informações de uso.

Módulo 1 — Fundamentos

O que são os banhos de ervas? São preparações feitas com plantas escolhidas de acordo com uma finalidade[cite: 2]. A escolha não deve ser aleatória: cada erva precisa ter uma razão para estar naquele banho[cite: 2].

A finalidade vem antes da erva

  • Observe o que você está vivendo no momento[cite: 2].
  • Escolha uma finalidade clara[cite: 2].
  • Selecione a erva principal e os complementos[cite: 2].
  • Entenda o motivo de cada ingrediente[cite: 2].

Preparo-base para folhas e flores

1. Aqueça 1 litro de água. 2. Desligue o fogo antes de colocar as ervas. 3. Acrescente folhas ou flores. 4. Tampe por 10 minutos. 5. Coe e aguarde temperatura agradável[cite: 2].

Módulo 2 — Tipos de Ervas

A classificação de ervas quentes e frias varia conforme a perspectiva utilizada. Neste material, ela é apresentada conforme a orientação da Maria[cite: 2].

Uma erva forte para limpeza pode não ser adequada para uso frequente. Já uma erva de equilíbrio cumpre função complementar suave[cite: 2].

Banhos Direcionados a Exu

Práticos, focados em movimento, clareza e firmeza. Validados pela Maria[cite: 2].

1. Banho de Exu para Movimento

Direcionamento: Exu • Finalidade: Movimento

Ervas: Alecrim, Manjericão, Louro[cite: 2].

Por que: O alecrim representa disposição; o manjericão renovação; o louro realização[cite: 2].

"Que eu reconheça o que está parado e tenha coragem para movimentar o que depende de mim."[cite: 2]

2. Banho de Exu para Comunicação e Firmeza

Direcionamento: Exu • Finalidade: Posicionamento

Ervas: Manjericão, Hortelã, Alecrim[cite: 2].

"Que minhas palavras tenham clareza, firmeza e responsabilidade."[cite: 2]

Segurança e Uso Responsável

Os banhos deste material são estritamente de uso externo. Não ingira as preparações[cite: 2].

Evite contato com olhos, mucosas e feridas. Em caso de irritação, suspenda o uso imediatamente[cite: 2]. O banho não substitui acompanhamento médico ou psicológico[cite: 2].
